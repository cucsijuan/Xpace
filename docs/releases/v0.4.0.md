## What's new

**Updates by themselves.** At start the game looks for a newer release and offers it with its notes: Update downloads it, closes the game, installs it over this copy and starts it again. A version can be skipped, and the check can be turned off in Settings (General). Copies from before this one must be updated by hand once.

**Menu dust.** The specks streaming past the main menu's ship are smaller and stretch a little as it speeds up.
